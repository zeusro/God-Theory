# 序言

佛教是神论的一个真子集。在佛教里面，有一种感官认识理论。

越好看的妹子，第六感越准。
她们总是能够根据一点蛛丝马迹，判断对象是否出轨。在我看来，第六感是**思维分析能力**。

对时间的感知就是第七感。只有理解了第七感，才能理解我所定义的一维世界。

理解第七感可以看破生死，在《火影忍者》里面叫做轮回眼。拥有轮回眼的人，可以辨明事物的生存，消亡规律。

第八感就更虚了，按照净空老法师的理解，[整個宇宙是一個阿賴耶](https://www.youtube.com/watch?v=4av6HGl7LMo)。
理解第八感，就是理解意识/物质世界（二维世界）的关键。“[要把不善的记忆清除掉](https://www.youtube.com/watch?v=puUNFIimAX4)。”
放下执念，立身成佛。
不过我更喜欢称之为幽默感。

第八感也叫忘性。
理解第八感，如果不靠老人痴呆症的话，最简单的方法是不吃药，靠自身意志力克服所有精神类疾病。
把世界理解为真实的幻象。
还有一种方法是学习闹市中冥想。

第九感叫真如心，即自性清净心。
真如心不叫佛性，而是神性。神性是唯一的究极真理。
简单一句话概括，**我心中之火永恒不灭**。

宗教本一源。

迷信神明拯救，只会被神明诅咒。
神性自然有，不信自然无。
相信自己，就是最好的信仰。
