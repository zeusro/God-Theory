# Glossary

## Cause and Effect Law

Result precedes cause (process).

## Generalized Game Theory

Past non-cooperative game theory models were primarily based on the game player, and the game player is mostly a person.

In generalized game theory, the game object can be time—a game based on a time series database, using everything around us as the player.

Everything around us can be static objects (whose strategy is to remain still), man-made creations (like an elevator), the sky (the alternation of the sun and moon, weather changes as the sky's "strategy"), or even non-existent elements (like a god).

Therefore, even if it appears to be just one person, it is still a game.

## P Equilibrium

In a game between one person and everything, P Equilibrium is an equilibrium achieved within a finite timeframe where humans and everything coexist harmoniously.
